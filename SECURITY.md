# Workspace Security Policy

Do not report suspected vulnerabilities, credentials, private URLs, sensitive
logs, or exploit details in a public issue. Use GitHub private vulnerability
reporting when available, or contact the repository owner privately.

This foundation has no application runtime. Future source, workflows, adapters,
and documentation that can affect Workspace security are in scope. Engineering
Platform, Forge, TDE, and DJConnect remain separate systems; identify every
affected boundary in cross-repository reports.
